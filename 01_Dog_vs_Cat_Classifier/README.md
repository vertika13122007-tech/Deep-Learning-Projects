# 🐶🐱 Dog vs Cat Image Classifier using CNN

This project implements a Convolutional Neural Network (CNN) using TensorFlow/Keras to classify images of dogs and cats.

The model was trained on the Kaggle Dogs vs Cats dataset and achieved approximately **95–96% validation accuracy**.

The project demonstrates the complete Deep Learning workflow including:

- Data preprocessing
- CNN architecture
- Model training
- Evaluation
- Prediction
